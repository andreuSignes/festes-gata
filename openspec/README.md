# openspec/

This directory holds the **spec-driven change plan** for the project.
It is intentionally excluded from version control (see `.gitignore` at
the repo root) because the specs are not part of the deployable site —
they are working notes for the team and the agents building it.

The active change folder is:

- [`changes/festes-gata-2026/`](changes/festes-gata-2026/) — the
  2026 festival program site. Open
  [`changes/festes-gata-2026/proposal.md`](changes/festes-gata-2026/proposal.md)
  for the intent and scope, then
  [`changes/festes-gata-2026/design.md`](changes/festes-gata-2026/design.md)
  for the architecture, then
  [`changes/festes-gata-2026/tasks.md`](changes/festes-gata-2026/tasks.md)
  for the ordered work units.

Specs (the contract with the implementation) live under
[`changes/festes-gata-2026/specs/`](changes/festes-gata-2026/specs/).

Archived changes, once shipped, move to
[`changes/archive/`](changes/archive/).
